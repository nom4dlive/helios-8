# helios-8
Demo interativa do sistema solar concluída: Sol e 8 planetas com shaders GLSL procedurais (bandas, manchas, crateras, calotas, continentes, nuvens, anéis com lacuna de Cassini), 15 luas nomeadas e clicáveis, câmera com perseguição orbital, raycasting para seleção, painel de dados (nome, tamanho, distância, período), controles de play/pause/velocida
